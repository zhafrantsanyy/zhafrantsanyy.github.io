03 Projects

Things I actually shipped.

Four public repositories — an automation pipeline, two operational dashboards and a marketplace. Every one of them started as somebody's spreadsheet.

01 JavaScript

financial-reporting-pipeline

Qudamah · n8n · 61 nodes · ~4k lines of JS

A single n8n workflow that pulls invoices, inventory and the chart of accounts out of Accurate Online, merges them with the team's Google Sheets, computes the operational and financial metrics, renders self-contained HTML dashboards and delivers everything to Telegram at 07:00 — then answers follow-up questions as a conversational analyst.

  • P&L summed from leaf GL accounts after the parent balance silently hid IDR 256M of owner draw
  • Per-sheet column fingerprinting, so a September row is never read through a July column map
  • Script-free HTML dashboards — Telegram's document viewer runs no JavaScript
n8nOpenAITelegram APIGoogle Sheets Repository
02 TypeScript

TJS-Lumber

TJS Logtrade · internal dashboard for a timber broker

Next.js 15 App Router on Supabase: live stock, supplier reliability scoring, price history and a per-pallet quality-control sheet. Reads go through Server Components, writes through Server Actions, and every route sits behind two independent auth checks.

  • QC maths verified against a real grading document — 20 pallets, 2,345 OK pieces, 2.29% defect
  • Paste-a-batch parser that accepts whatever separator the buyer's document used
  • Print stylesheet that turns the QC screen into a clean sheet ready to send

03 JavaScript

kalamekardemo

Kalamekar · marketplace for Indonesian local florists

Buyers browse ready-made arrangements or build their own bouquet on a drag-and-drop canvas with live pricing, then check out into Supabase. Phase 1 runs as a concierge model: the order is validated on the site and handed to a partner florist over WhatsApp.

  • Bouquet builder canvas that prices flowers, filler, size and wrapping in real time
  • Row Level Security so a visitor can create an order but never read anyone else's
  • Centralised design tokens — no hex codes hardcoded in components
